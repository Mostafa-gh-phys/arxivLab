**Email:** [mostafaghorbani036@gmail.com](mailto:mostafaghorbani036@gmail.com)

## ✅ Features

❇️ Search for and save papers from **arXiv** and **INSPIRE-HEP**.

❇️ Link to the **Zotero** web library and the local app.

❇️ A library for saving papers.

❇️ Sync the library to Google Drive and custom cloud storage services.

❇️ MCP mode for AI agents via local and online AIs.

❇️ Network and DNS settings.

❇️ Reference export as BibTeX.

## 📦 Installation

### Linux

First, download **Gear Lever**. You can find it in your Linux distribution’s repositories or stores.

### Windows

Portable and installation editions are available.

### macOS

ARM (Apple Silicon) builds are available in `.dmg` and `.zip` installation formats.
